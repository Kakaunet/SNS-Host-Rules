# SNS-Host-Rules
An Among Us BepInEx mod made to enforce SNS (Shift 'N Seek) rules.

### Download
#### Requirements
The mod is only compatible with Windows 10 and 11 (x64).\
You MUST have Among Us v19s from Steam, as well as BepInEx installed.

You can install BepInEx by following these intructions:
- Go to https://builds.bepinex.dev/projects/bepinex_be
- Open the latest version (under Artifacts, the very first one that appears)
- Search for a version named "BepInEx-Unity.IL2CPP-win-x64-[something].zip"
- Download it and extract it directly into your Among Us' installation folder (Open Steam -> Library -> Among Us -> Manage -> Browse local files)
- Launch Among Us and wait until it fully loads, then close it
- Continue with the mod installation

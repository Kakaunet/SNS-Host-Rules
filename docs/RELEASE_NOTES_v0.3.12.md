# SNS Host Rules v0.3.12 — Multiplayer-tested

**Host-only Shift ’N Seek rules enforcement for Among Us**

**Compatibility:** Among Us 2026.9.29 · Windows Steam x64 · BepInEx 6 Unity IL2CPP (Windows x64). Other game versions and operating systems have not been verified.

## Download and installation

**Download the attached `SNSHostRules.dll` under Assets. Do NOT use “Source code (zip)” as the mod installer.**

1. Install BepInEx 6 **Unity IL2CPP Windows x64** from https://builds.bepinex.dev/projects/bepinex_be, extracting into the Among Us game folder.
2. Launch and close the game once to initialize BepInEx.
3. Copy `SNSHostRules.dll` to `<Among Us folder>\BepInEx\plugins\`.
4. Launch the game, create a lobby as the host, and press **F7** to enable Shift ’N Seek enforcement.

Only the **host** needs the mod; other players join with their unmodified Among Us installation. To join online, share the lobby code (registered modded lobbies may not be visible in normal public matchmaking).

## Features

- Enforces Shift ’N Seek restrictions on kills, sabotage, doors and vents.
- Rules announcements, offender warnings/penalties and meeting safeguards.
- Official Among Us mod stamp and host-only +25 registration on official servers.
- Tested by the maintainer in multiplayer on the specified game version.
